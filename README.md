# Portfolio - Muhammad Asad Haider

A premium, fully responsive personal portfolio website built for Muhammad Asad Haider.

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5 (CDN)
- Vanilla JavaScript (ES6)
- AOS (Animate On Scroll) Library
- Typed.js
- Font Awesome & Bootstrap Icons

## How to View
This project requires no build tools or servers. To view the website:
1. Extract or clone this folder.
2. Double-click on `index.html` to open it in your web browser.

## Structure
- `index.html` - The main structure of the website.
- `style.css` - Custom styling, glassmorphism UI, and variables.
- `script.js` - Logic for typing animation, scroll effects, filtering, and contact form validation.
- `profile.png`, `fives-kitchen.png`, `velvet-vibe.png`, `resume.pdf` - Media and document files.

## Customization
- To update your profile picture, replace the placeholder in `index.html` (inside the `#home` section).
- To add your actual resume PDF, place it in the same directory and name it `resume.pdf`.
